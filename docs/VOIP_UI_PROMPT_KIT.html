01

How to use this kit

GPT Image is good at composition, hierarchy and atmosphere; it is unreliable at dense text. Treat each prompt as a art-direction brief for the layout, then rebuild the winning frame in Figma with real copy. That is faster than asking the model to invent a product.

STEP 01

Paste the DNA first

Every prompt starts with the same locked style block. That is what makes the four screens read as one product instead of four different SaaS templates.

STEP 02

Add one screen brief

Use the screen prompt exactly as written. Keep the sample French data: it gives the model a realistic density and stops it from filling space with invented widgets.

STEP 03

Generate, then rebuild

Ask for three variants. Pick the strongest hierarchy, then recreate it in Figma with your components. Generated text is a placeholder, never production copy.

The one rule that saves hours. Generate at 1536×1024 landscape, straight-on, with no device frame. The moment you ask for a laptop mockup or a presentation board, the model spends its detail budget on the frame instead of the interface.

The design DNA

A calm, editorial enterprise tool: warm paper, a deep navy rail, white working cards, and magenta used only where something is live or primary. Dense information, generous breathing room, no decorative noise.

  • Magenta means live, active or primary — never decoration.
  • One focal point per screen: the person, the next call, the review, the floor.
  • Cards are white on paper with a 1px hairline; no heavy shadows.
  • Initials avatars only. No stock portraits, no AI faces.
  • 8px spacing grid, 12-column layout, everything aligned to a edge.
  • No gradients, glass, neon, 3D or floating blobs. Ever.

Keep the set coherent

Four separate generations drift. These are the guardrails that keep them looking like four views of one product rather than four competitors.

Negative prompt · append to every generation

No gradients, glassmorphism, neon, 3D, isometric view, laptop mockup, browser chrome, hands, people, stock photography, emoji, lorem ipsum, greeked or blurred text, invented logos, watermarks, purple-blue AI gradients, oversized pill buttons, heavy drop shadows, tilted perspective, dark mode, cluttered panels, overlapping cards, cut-off text, floating decorative shapes.

The consistency checklist

  • Same 64px rail, same 64px top bar, same 12px card radius in every screen.
  • Magenta appears only on live, active or primary; if it is decorative, remove it.
  • One page title per screen, one primary action, no competing CTAs.
  • Keep the sample French names and companies across all four images.
  • Every screen uses the same three type sizes: 28, 17, 12.
  • No screen introduces a new accent color, chart style or icon family.

Iteration recipe

01 · Three variants, one brief

Generate three images without changing the prompt. Pick the one with the clearest focal point, not the prettiest one.

02 · Fix the text after

Regenerate once if labels are garbled. If it persists, keep the layout and rebuild the copy in Figma; do not fight the model.

03 · Lock the grid

Use the same prompt prefix and the same 1536×1024 ratio for all four. Cropping one screen differently breaks the set.

04 · Judge at thumbnail size

Shrink the image to 25%. If the hierarchy disappears, the layout is too busy; remove a card, not the whitespace.

The test of a good generation. At thumbnail size you can still tell where to look: the person in the Cockpit, the next call in the Queue, the confirm button in Zéro Admin, the amber row in Pilotage. If everything competes, the screen has failed regardless of how polished it looks.
